# CAPY BK release checklist

### Editorial / claims
- [ ] TikTok story tells complete ~2 minute narrative; YouTube ~10 minute version is substantively more detailed.
- [ ] Technical reviewer checks: tank inclination vs free surface, fuel level vs quantity, IMU limitations, sensor-type assumptions, timing and engine consumption confounders.
- [ ] No assertion that FuelGuard has field-proven theft detection, calibrated accuracy, low false alarms or production deployment absent independent evidence.
- [ ] Any real vehicle or machine-specific facts require verified manual or documented public source; concept visuals labeled as illustrations.
- [ ] No personal records / machine ownership / customer privacy / finance sources disclosed.

### Visuals / audio
- [ ] Approved Capy identity match: round face, short paws, cheerful, BK shirt, studio/mug.
- [ ] Accuracy of exact school logo checked, and permission/attribution requirements reviewed before commercial publishing.
- [ ] No uncontrolled AI-generated fake technical diagrams or mangled text/brands.
- [ ] Audible Vietnamese dialogue (not music only), consistent levels; lip-sync confirmed for speech clips.
- [ ] Rights for footage, reference art, music, SFX and AI voice usage documented.
- [ ] Readable captions and subtitle timing, cross-platform safe areas.
- [ ] 9:16 1080×1920 30fps and 16:9 1920×1080 30fps delivered as H.264+AAC MP4.
- [ ] Check export files actually play on Windows/phone and have video + audio streams, correct duration.

### Workflow
- [ ] Asset manifest with hashes, provenance, model/prompt and approvals.
- [ ] Codex build scripts reproducible; no hidden absolute machine paths; smoke tests.
- [ ] CapCut Pro AI credits estimate approved; no automated editing assumptions.
- [ ] Final owner approval. No automatic platform publication without explicit instruction.
