# Capy BK production pipeline — CapCut Pro first

## Constraints / format
- **TikTok main cut:** target **~120 seconds**, portrait 9:16, export 1080x1920 at 30 fps.
- **YouTube long form:** target **~600 seconds**, landscape 16:9, export 1920x1080 at 30 fps.
- Separate script and layout adaptations; do not auto-crop 16:9 blindly into a 9:16 edit.
- `assets/` may contain only approved, public-safe reusable art and properly licensed sound. Do not upload proprietary or customer machine telemetry into this **public** repository.

## Recommended tool split
| Stage | Lead | Deliverable |
|---|---|---|
| Editorial | ChatGPT / owner | creative brief, 2 min and 10 min narrative structures |
| Technical | owner / independent reviewer | factual review notes, diagram approval |
| Visual asset production | image/video agent + **CapCut AI Image to Video** | shot clips, reusable transparent/Png layers, mascot consistency proofs |
| Voice/character | CapCut **Text to Speech** and **AI Dialogue Scene**, optional owner voice | dialogue stems, 3–6 sec lip-sync test |
| Assembly | Codex | repeatable FFmpeg/prep scripts, precise file naming, SRT, conversion/verification; *not* a substitute for frame-accurate creative animation |
| Finish | **CapCut Pro (owner/editor)** | sound design, b-roll, layered captions, music, color, timing, export |
| QA | owner / reviewer | accepted deliverable, upload decision |

## CapCut-first proof of style (BEFORE both episodes)
1. Start from approved static Capy frame extracted from approved GIF; do not ask the image generator to redraw its identity.
2. In CapCut desktop, look for **AI media > AI video > Image to video**. Import the still; test 4–6s action: 'blink, raise short paw, happy body bounce, slight natural head tilt; preserve shirt emblem, mug, set composition; do not change camera or character geometry.' Exact menu/models may vary by platform/account.
3. Try **AI dialogue scene**, if present, using the same image and one Vietnamese dialogue line. Test whether stylized capy face lip-sync works. Otherwise, separate TTS narration and manual 2D visemes; do not force poor human-style face animation on a cartoon animal.
4. Use **Text > Text to Speech** for temporary Capy voice. Export voice track/clip. Compare to owner's voice and decide character casting before making 100+ seconds.
5. Test **AI Video** on an illustrative construction-machine scenic cutaway. Verify hands, logo, machinery geometry and motion. Treat technical cross-sections generated by AI as unverified: use hand-built layers or validated schematics instead.
6. Produce a polished **15–25 second** vertical proof of style with speech, scene change, music ducking, subtitle and one technical figure.
7. Record generation time, AI credits consumed, aspect ratio, visual artefacts, quality and repeatability. Owner chooses pipeline based on actual output.
8. Only after pass, scale to TikTok ~2min and YouTube ~10min as independently timed narratives.

Per shot:
- `SC01_studio_capy_image.png` / `SC01_anim_1080x1920.mp4`
- `SC01_voice.wav` or `SC01_voice_temp.wav`
- `EP01_TIKTOK_vi.srt`
- `SC01.notes.md` describing licensed source, duration, version, prompt, issues
- All voice stems 48kHz WAV if practical; all videos H.264 MP4 and a constant frame rate where possible.

CapCut project is the authoritative **manual final edit** until automation is explicitly verified; don't fabricate a CapCut native project file. Keep render-ready, standard media for agent exchange.

## QA / publishing gate
- Audio: voice is present, intelligible, does not clip, background ducked under speech; no 'silent demo' presented as final.
- Video: continuous motion rather than static title slides, correct logo/mug, no flicker or character drift.
- Facts: level vs volume, geometry and tilt, operating context, suspicious anomaly vs proof of theft.
- Deliverables: 2min/10min separate masters, subtitles, thumbnail, description, rights checklist.
- No agent posts or merges to main without owner approval.
